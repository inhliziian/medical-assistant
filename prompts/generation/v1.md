# Generation prompt (shared by all generation agents)

You are writing realistic clinical documents for a dataset. Each document is generated from one
**seed**. The seed's `facts` are the ground truth and must be reproduced exactly; the `hints` control
form. Output is plain text, one file per seed, at `data/clean/{id}.txt`. Do not add typos or formatting
noise: a separate script does that deterministically.

## Hard rules on facts (the golden labels depend on these)

1. **State every fact in `facts`.** Every diagnosis, every medication name, every lab value with its
   number must appear in the text.
2. **Never add a fact that belongs to a schema field.** Do not invent extra diagnoses, medications or
   lab values. Non-schema content is fine and encouraged (see distractors).
3. **Nulls mean silence.**
   - `patient_age: null` → the text never states or implies an age (no "elderly", no "teenager", no date of birth).
   - `patient_sex: "unknown"` → use "the patient" / "pt" only, no he/she, no "Mr/Mrs", no gendered terms.
   - a medication with `dose: null` → mention the drug without any dose.
   - a medication with `frequency: null` → mention it without any frequency or schedule.
   - a lab value with `unit: null` → write the number without a unit.
4. **Numbers exactly as given.** `6.8` is written `6.8` (the noise script may later turn it into `6,8`).
5. **Frequencies** in the text may be written naturally (BID, twice daily, "двічі на день", q12h, OD,
   nightly, prn, weekly), as long as they map unambiguously to the seed's normalised value:
   `1x/day`, `2x/day`, `3x/day`, `4x/day`, `weekly`, `as needed`.
6. **Urgency must be readable from the text.** `urgent` → words like urgent, immediately, same day,
   терміново, негайно. `soon` → within days or 1–2 weeks, "незабаром", "протягом тижня".
   `routine` → scheduled follow-up in weeks/months, or no time pressure.
7. **follow_up_required** → `true` means the text names a follow-up (visit, repeat test, referral);
   `false` means the text says no follow-up is needed or simply mentions none.
8. **Diagnoses** may be phrased as a clinician would (abbreviations, Latin, Ukrainian) as long as a
   clinician could map them back to the seed's English term. E.g. "ХХН 3 ст." for
   "chronic kidney disease stage 3", "CAP" for "community-acquired pneumonia", "T2DM", "HFrEF".
9. **No personal data.** No names, no dates of birth, no addresses, no ID numbers, no phone numbers.
   "The patient", "pt", "пацієнт/пацієнтка" only. Hospital or clinic names: generic ("the clinic").
10. **Report type must match.** `report_type` must be visibly that kind of document:
    - `consult` — first visit / consultation: history, exam, assessment, plan.
    - `progress_note` — follow-up or SOAP note: short, references prior visit.
    - `discharge` — discharge summary: admission reason, hospital course, discharge meds, plan.
    - `referral` — referral letter from one doctor to another: reason, brief history, question.
    - `lab` — laboratory report: a list of analytes with values, a short interpretation line.
    - `radiology` — imaging report: exam, technique, findings, impression (hints.modality).

## Form (from `hints`)

- `language`: `en` → English. `uk` → Ukrainian throughout, but keep drug names, lab abbreviations
  (CRP, HbA1c, TSH) and units in Latin script, as Ukrainian doctors do. `mixed` → a Ukrainian
  document with whole phrases or sections in English (or vice versa), the way a bilingual clinic writes.
- `style`: `soap` → SUBJECTIVE / OBJECTIVE / ASSESSMENT / PLAN headers. `narrative` → prose paragraphs.
  `dictation` → transcribed dictation: "Patient is a ... presents with ...", some run-on sentences,
  section words spoken inline. `bullet` → terse bullet lists.
- `target_words`: hit roughly this length (±25%).
- `distractors`: include these non-schema sections realistically (allergies, family history, social
  history, vitals, physical exam, plan details, review of systems). They make extraction harder and are
  not labelled.
- `specialty`: write with that specialty's vocabulary.

## Output

Plain UTF-8 text. No markdown fences, no title line like "Note 1", no commentary. Start directly with
the document.
